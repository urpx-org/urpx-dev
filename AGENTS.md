# AGENTS.md

Instructions for automated agents and coding assistants working in this repository.

This repository is the design and process record for URPX, the Utility Rate Plan Exchange ontology: tasks, specifications, working reports, roadmaps, and development samples. It is not the standard itself; see [`urpx-org/urpx`](https://github.com/urpx-org/urpx) for the ontology, SHACL shapes, and curated test cases.

## Looser than the standard repository

This repository does not carry the length and verbosity limits the standard repository's `AGENTS.md` sets for issues and pull requests, because it is not on the critical path to a release tag. Ordinary judgment about concise, reviewable writing still applies.

## What still holds

- **No internal process framing.** Do not reference private repositories, internal project names, working sessions, codenames, or a commercial platform built on this standard.
- **Careful attributions.** Do not assign authorship or credit without a clear basis in the record.
- **Plain, factual voice.** Describe the change or the design question, not the process that produced it.
- **Prose formatting.** Write for a person reading and reviewing the text. Do not hard-wrap a paragraph mid-sentence to hit a column width; a paragraph is a single line in the source. Keep paragraphs and sentences short.
- **Follow [CONTRIBUTING.md](CONTRIBUTING.md)** for file naming, frontmatter, lifecycle prefixes, and the public-ready bar for anything added under `dev-docs/`.

## New directories

Do not create a new directory beyond the subfolders `CONTRIBUTING.md` lists without prior working group discussion. The first place for this discussion is a working group meeting; a focused GitHub issue is also acceptable.
